# Original causal knowledge animation

Use one workflow from reference study to post-publication learning. This public skill contains reusable methods, not private project authorization, credentials, a rendering engine, reference media or a promise of results.

1. Read [reference study](references/reference-study.md). Use the fixed two-route style treatment and quarter-second target study. For browser viewing, record actual displayed time intervals, drift, reuse and gaps; use source PTS only when genuinely decoded. Distinguish previews from full films and silent visuals from audio review.
2. Read [causal planning](references/causal-planning.md). Start with a recognizable everyday curiosity, not a calculation exercise. Establish rules before outcomes, follow identifiable objects, preserve competing explanations and controlled variables, and show before/action/after states.
3. Read [rendering and QA](references/rendering-and-qa.md). Select the medium for the explanation, use a reproducible time function and shared state, validate actual frames and motion. Technical checks are not comprehension tests.
4. Write a scene contract using [the schema](references/scene-contract.md) and [example](references/scene-contract.example.json). Run scripts/validate_scene_contract.py with its JSON path. This checks structure only, not rights or authorization.
5. Read [publication and analysis](references/publication-and-analysis.md). Confirm the operator's current authorization and its prerequisites, select licensed platform music if requested, inspect the final submission, verify publication, and collect daily per-video analytics with definitions and dates.
6. Retain [attribution and license boundaries](references/attribution.md). Do not copy private logs, reference frames, runtime instructions, account data or secrets into public releases.

Current technical evidence must be recorded per environment. CPU-rendered output does not establish working browser WebGL/PBR; an offline material still does not establish an animation pipeline. Reading an Opus-named skill does not invoke an Opus model. Never claim untested capabilities or invisible quality checks.

For revision work, bind observation, actual modification and verification to the same output version; see [the revision evidence chain](references/reference-study.md#revision-evidence-chain). Use [endpoint handoffs and occlusion regressions](references/rendering-and-qa.md#endpoint-handoffs-and-occlusion-regressions) when a result must visibly travel between stable subjects. Optional procedural sound design requires its own [event-level determinism and interface checks](references/rendering-and-qa.md#optional-procedural-audio-static-findings), not merely a fixed global seed.

For static SVG captions, use the [actual-font ink-bounds check](references/rendering-and-qa.md#actual-font-caption-boundaries). It measures supplied trusted samples without wrapping or rewriting text; geometry, normal-speed reading and publication checks remain separate.
