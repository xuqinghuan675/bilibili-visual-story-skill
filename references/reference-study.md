# Evidence-bounded reference study

For a legally accessible source, record its public URL, version/hash when available, dimensions, duration, source frame timing, target sampling times, chosen source PTS/display interval, review coverage and audio status. Use 4 Hz target sampling (0, 0.25, 0.5 seconds, etc.) and inspect key actions/transitions more densely. Sampling frequency is not delivery frame rate. Do not interpolate evidence or fill gaps with cached browser screenshots. Hash uniqueness only helps detect duplication.

Case evidence: the public preview of “鸽子的迷信” at https://github.com/HeyChengC/vibe-knowledge-film/blob/main/examples/pigeon_B.gif is 32.8 seconds, 800×450, 328 source frames at 10 fps. Its complete preview was studied through 132 quarter-second target samples, plus 60 source-time detail samples. A target such as 0.25 seconds selects the source frame displayed from 0.20 to 0.30. This is NOT the unseen original full film, provides no audio evidence, and does not establish original 30/60 fps motion smoothness. This completes a study scoped to the selected public preview. Do not invent a requirement to obtain an unseen longer original when the task only requests one reference clip. Missing media for an optional additional study does not invalidate this completed scope.

Transferable lessons: establish the timer before reward; keep the timer and alternative explanation visible; show closed gate, opening, falling food and response; repeat an action without a reward before the next timer-triggered reward. This separates correlation from causation. Change shot scale to emphasize the cause without losing object identity. Text can remain stable while objects perform the evidence. Do not copy the bird, exact text, composition sequence or media. The example is not an independent scientific validation of the depicted experiment.
